# Inoculate

A structured, survey-informed approach to sky subtraction for standard VIRUS 3‑dither exposures.

Inoculate will provide tools to model the sky signal coherently across fibers, amplifiers, visits, and time, with the goal of minimizing systematic residuals that limit faint emission‑line science.

This is an early scaffolding of the package. The science documentation and API will grow here.
