# Quickstart

This quickstart demonstrates importing Inoculate and checking its version. Scientific usage examples will be added as the algorithms mature.

## Python example

```python
import inoculate as ino
print(ino.__version__)
```

Expected output (version may differ):

```
0.0.1
```
